# Roadmap

This project is intentionally compact, but the roadmap highlights the next logical improvements.

## Planned improvements

- Expansion to additional providers
- Better per-provider key configuration
- Persistent dashboard backend
- API key auth and rate limiting
- Request hashing and response caching
- Streaming passthrough support
- Structured search parsing
- Zod request validation
- Observability and tracing
- Docker support
- Typed error contracts across SDKs

## Current status

The repo is active and already includes the core abstraction, SDKs, search support, and local test pipeline.
